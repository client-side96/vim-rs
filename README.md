# vim-rs

A blazingly fast... just kidding.

## Motivation

As software developers, we use text editors every day. But we don't really
think about how they work. This project attempts to demystify the inner workings
of a terminal text editor by building one from scratch.

## Goals

- [ ] Reading and displaying user input with keystrokes

- [ ] Basic cursor movement with arrow keys

- [ ] Handling of special keys like `Backspace`, `Enter`, `Tab`

- [ ] Saving user input to a new file

- [ ] Reading and displaying file contents

- [ ] Saving user input to an existing file

- [ ] Showing line numbers

## Bonus Goals

- [ ] Separation of Normal and Insert mode

- [ ] Basic commands to save and quit (`:w`, `:q`)
